# v1.1 Plan: H-1B Wage Intelligence

## Summary

Add a v1.1 feature that analyzes H-1B offered wages using public DOL OFLC Labor Condition Application data. This is framed as LCA-based wage intelligence, not exact lottery winners or individual selected beneficiaries, because USCIS selection notices and beneficiary-level salary data are not public.

## Key Changes

- Add a new DOL LCA ingestion pipeline using official OFLC Performance Data files for LCA Programs: `LCA_Disclosure_Data_FY2026_*` and, where available, `LCA_Worksites_FY2026_*`.
- Add new DuckDB tables:
  - `h1b_lca_cases`: cleaned case-level H-1B LCA records.
  - `h1b_lca_worksites`: normalized worksite records where available.
  - `h1b_wage_summary`: derived aggregates by employer, SOC, state, city, wage level, and quarter.
  - `h1b_cap_season_proxy`: filtered proxy for likely FY2027 cap-season new-employment filings.
- Add one script, `scripts/extract_h1b_lca_data.py`, with this default command:

```bash
python scripts/extract_h1b_lca_data.py --fy 2026 --quarter latest
```

- Store raw files under `data/raw/dol_lca/` and processed CSVs under `data/processed/`.

## Data Rules

- Include only `VISA_CLASS = H-1B`.
- For dashboard salary analysis, prefer `CASE_STATUS = Certified`.
- Use DOL-provided `PW_WAGE_LEVEL` when present; map Level I-IV to weighted lottery entries: I=1, II=2, III=3, IV=4.
- Normalize offered wage to annual dollars:
  - Year = unchanged.
  - Month = x12.
  - Bi-weekly = x26.
  - Week = x52.
  - Hour = x2080.
- If wage range exists, use `WAGE_RATE_OF_PAY_FROM` as the conservative offered wage and retain `WAGE_RATE_OF_PAY_TO` for future tooltips.
- Define `h1b_cap_season_proxy` as certified H-1B LCAs with new employment positions and employment start dates around the FY2027 cap start window, centered on October 1, 2026.
- Always show a caveat: one LCA can cover multiple workers, public files exclude worker names, and LCA certification does not prove lottery selection or petition approval.

## Dashboard Changes

- Add a new section after the existing H-1B deep dive: **H-1B Wage Intelligence**.
- Add stat cards:
  - Certified H-1B LCAs analyzed.
  - Cap-season proxy positions.
  - Median offered annual wage.
  - Share of Level III/IV filings.
  - Weighted-entry mix.
- Add charts:
  - Wage-level distribution: Level I-IV count and weighted entries.
  - Top employers by cap-season proxy positions, with median offered wage.
  - Top occupations by SOC title, with median wage and filing volume.
  - Salary distribution histogram with wage-level coloring.
  - State/city table for geographic wage hotspots.
- Keep the dashboard static by embedding the derived chart data into `docs/dashboard.html`.

## Test Plan

- Validate ingestion row counts against the downloaded DOL Excel files.
- Verify all annualized wages are positive and plausible; flag outliers above $1M or below federal minimum wage equivalent.
- Confirm all wage-level values are one of Level I, II, III, IV, or Unknown.
- Check DuckDB tables load cleanly and dashboard queries return non-empty results.
- Regenerate `docs/dashboard.html` and verify the new section renders without breaking existing V7 charts.
- Run a smoke query for top employers, median wage by level, and cap-season proxy count.

## Assumptions

- v1.1 uses public DOL LCA data as the source of salary truth.
- Exact FY2027 selected beneficiaries and exact lottery picks remain out of scope.
- The dashboard remains a single static HTML file generated from DuckDB.
- The implementation uses the latest official DOL LCA disclosure release available at build time; if only FY2026 Q1 is public, v1.1 ships with Q1 and supports quarterly refresh later.
